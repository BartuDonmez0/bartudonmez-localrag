# Mentoring Office Hours FAQ

## When are mentors available?

Weekdays **14:00–16:00** in room B-214, and asynchronously on the WhatsApp group after kickoff.

Questions about certificates, name corrections, and deadline changes go by email to the organizer (`barbg@microsoft.com`), not only to peer mentors.

## What mentors will not do

- Rewrite your entire project for you the night before the deadline
- Sign incomplete work as completed
- Debug cloud OpenAI keys for a project that must be Foundry Local offline
- Accept a video that never shows a running application

## What to prepare before asking for help

1. Minimal reproduction (exact error text)
2. Whether `npm run ingest` succeeded and how many chunks were created
3. Whether Foundry status is ready
4. Your free RAM estimate

## Pair work policy

Collaboration is allowed for learning. Submission must be **your** repository and **your** demo video. Copied repos without attribution may be rejected.
