# Final Delivery Packet Checklist

Before you message the organizer that you are finished, verify every box.

## Product checklist

- [ ] `npm run ingest` indexes your documents without errors
- [ ] `npm start` reaches Offline ready
- [ ] At least three domain questions answer correctly with Sources visible
- [ ] At least one unknown question refuses correctly
- [ ] Upload of a new `.md` file works (or you document why you disabled it)

## Repository checklist

- [ ] Public GitHub URL works in a private browser window
- [ ] README in English (or bilingual) explains how to run
- [ ] No `node_modules` or model weights committed
- [ ] License acknowledged (MIT for this sample lineage)

## Admin checklist

- [ ] Name and email correct on the summer school list (certificates print these)
- [ ] GitHub link pasted into the list or emailed
- [ ] ~3 minute video link pasted into the list or emailed
- [ ] If your school needs internship paperwork, request signature explicitly

## Suggested demo script (timing)

| Minute | Action |
|--------|--------|
| 0:00–0:30 | Introduce problem: offline grounded Q&A |
| 0:30–1:30 | Ask a specific lab question (hours, rubric, or error fix) |
| 1:30–2:10 | Show Sources + explain retrieve → augment → generate |
| 2:10–2:40 | Ask an unknown question; show refusal |
| 2:40–3:00 | State one lesson learned |
