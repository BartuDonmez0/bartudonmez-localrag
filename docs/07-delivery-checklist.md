# Summer School Project Delivery Checklist

This checklist matches the Microsoft Turkey CSU summer school expectations for the Local RAG project.

## Must deliver

1. A working offline Q&A assistant on your laptop.
2. A public GitHub repository with source code and a README.
3. A short video (about 3 minutes) explaining what you built and what you learned.
4. Correct name and email on the summer school list (certificates use that name).

## README should include

- Project purpose
- Architecture overview (client, server, RAG pipeline, SQLite, Foundry Local)
- Install and run steps
- Example questions that work
- Known limitations

## Demo tips

Show one answer grounded in a document, and one question the assistant correctly refuses when information is missing.
